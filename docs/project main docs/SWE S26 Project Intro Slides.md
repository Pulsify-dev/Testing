How to start?

● Form the teams.

● Note: Sub-teams (not the whole team): Same grade (vertical & horizontal grading).

● Choose tech.
● Unify Tasks.

Phases

● Phase 0:

○ Used Tools & language. And why?
○ Team members and Positions.
○ Preparing repo & Task Management Tool.

● Phase 1:

○ Code Style for each team.
○ Task division (Use task management tool if appropriate) .
○ System Design [With the help of open APIs].

Phases

● Phase 2:

○ 20% Of EVERY POINT.
○ Progress Report (Individual + Team-based).

● Phase 3:
○ 50%
● Phase 4:

○ 100% + additions!

Recommendations

● https://education.github.com/pack.
● Start learning early. Really, really early!
● Divide learning between sub-team members.
● Use support at tutorials. It’s part of the schedule.
● Single Duty “Be specific”.
● Open Source Projects.
● Use the tools!

Tips

● Transparency.
● Deep Understanding.
● Be Flexible:

○ No need to know everything before starting.
○ No need to know how to do every bit before starting.
○ Do the basic, Enhance, Iterate
